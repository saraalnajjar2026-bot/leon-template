# Leon Template Project

مشروع تصميم وتطوير موقع إلكتروني (Leon Template) لمادة تصميم وإدارة مواقع الإنترنت.

## وصف المشروع:
قالب ويب عصري ومتجاوب يتضمن واجهة رئيسية، قسم عن الموقع، ومعرض أعمال متكامل.

## محتويات المشروع:
- `index.html`: الصفحة الرئيسية للموقع.
- مجلد `css/`: يحتوي على ملفات التنسيق والستايل.
- مجلد `images/`: يحتوي على كافة الصور البصرية والشعار.# leon-template
